Integraciones

👥 Configuración del equipo

Comparte en un archivo (pm-equipo.json) lo común del equipo: URL de Jira / Azure DevOps, IDs de Microsoft y Google, canal del equipo y horarios. Nunca lleva tokens personales: cada persona pega el suyo. Si lo dejas junto al proyecto al compilar, el instalador lo aplica solo.

Te aviso cuando Claude termine una tarea o necesite tu permiso, y muestro una burbuja mientras trabaja. Añade unos hooks a tu ~/.claude/settings.json (con copia de seguridad).

🎫 Tickets del equipo

Tus tickets asignados aparecen en 📋 Día para añadirlos a tus tareas. Al completar la tarea en PM, el ticket pasa a "Hecho" y (en Jira y Azure DevOps) se carga el tiempo que mediste con el cronómetro. Los tokens se guardan cifrados.

🟦 Jira

Crea el token . En Jira Server usa un token de acceso personal y deja el correo vacío.

🐙 GitHub Issues

Usa el mismo token de GitHub de más abajo (permiso repo). Trae las issues abiertas asignadas a ti.

🟪 Linear

Linear → Settings → Security & access → Personal API keys.

🔷 Azure DevOps

User settings → Personal access tokens con permiso Work Items (Read & write).

Cerrar el ticket al completar la tarea
Cargar el tiempo medido como horas

Jira (registro de trabajo) y Azure DevOps (Completed Work).

Microsoft (Entra ID)

En → Registros de aplicaciones → Nuevo registro · redirección Cliente público → http://localhost · permisos User.Read, Mail.ReadBasic, Calendars.Read. El inquilino solo hace falta si la app es de "un solo inquilino".

Google
