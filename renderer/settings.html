Dónde se guardan

Copia de seguridad

Exporta la memoria del pollito para cambiar de PC. Las claves no se exportan.

Copia automática semanal

Guardo una copia cada semana en una carpeta sincronizada (OneDrive / Google Drive) y conservo las 6 últimas.

Contraseña de las copias

Opcional: cifra las copias (AES-256). Sin ella no se podrán abrir, ¡no la olvides!

Entre PCs y otras apps

Exportar a Markdown / Obsidian

Exportar solo cada noche

Borrar todos mis datos

Integraciones

🤖 Claude Code

Te aviso cuando Claude termine una tarea o necesite tu permiso, y muestro una burbuja mientras trabaja. Añade unos hooks a tu ~/.claude/settings.json (con copia de seguridad).

🧩 El pollito dentro de Claude (MCP)

Claude podrá leer y actualizar tus tareas, la cola, notas, recordatorios y límites (herramientas pm_…). Solo por tu PC (127.0.0.1) y con una clave secreta.

Claude Code

Se añade a ~/.claude.json (con copia de seguridad). Reinicia tus sesiones de Claude Code.

Claude Desktop

Para el chat de la app de Claude. Reinicia Claude Desktop después.

Línea de estado en Claude Code

Abajo en Claude Code: 🐣 42% · 🍅 12:30 · ✅ 3/7

⌨️ Comando pm en la terminal

Desde cualquier terminal: pm status, pm add "revisar PR", pm done 2, pm focus 50, pm queue …. Abre una terminal nueva después de activarlo.

🧠 Memoria de proyecto (CLAUDE.md)

Escribo en el CLAUDE.md del repo lo que sé de él (comandos, errores frecuentes, decisiones de tus notas, entregas), entre unas marcas; el resto del archivo no se toca.

🐙 GitHub

PRs que esperan tu revisión, CI fallido, aprobaciones y comentarios. Crea un token personal (permisos repo y read:org) y pégalo. PM solo lo usa para leer; se guarda cifrado.

💻 Carpetas con tus repos de git

Una por línea. Busco repositorios hasta 2 niveles dentro.
