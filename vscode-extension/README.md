# PM Pollito para VS Code

Tu pollito Project Manager en la barra de estado de VS Code:

- 🐣 **% de tu sesión de Claude** (se pone amarillo al 75% y rojo al 90%) con la predicción de a qué hora llegarás al 100%.
- 🍅 **Pomodoro** y ⏱ **cronómetro de tarea** en vivo.
- ✅ Progreso de tus tareas del día y 🔔 avisos sin leer.
- Clic → menú rápido: anotar, pomodoro, consumo, tareas, avisos, silenciar…
- `Ctrl+Alt+N` → anotar una tarea o un recordatorio (“recuérdame a las 3 revisar el PR”).

Necesita la app **PM Pollito** abierta. Solo habla con ella en tu PC (`127.0.0.1:47823`), nunca con internet.
